# Скриншоты для презентации

Положите сюда PNG или JPG с **точными именами** из списка — они автоматически появятся в `presentation.html`.

| Файл | Что снять |
|------|-----------|
| `01-hero.png` | Главный экран после входа (профиль или сайдбар) |
| `02-login.png` | Страница входа |
| `03-schedule.png` | График смен |
| `04-availability.png` | Карта возможностей |
| `05-daily-payroll.png` | Дейли или зарплата |
| `06-supply.png` | Заказ поставок |
| `07-chat-news.png` | Чат с бухгалтерией или лента новостей |
| `08-guru.png` | Раздел обучения DBT.INFO |
| `09-admin.png` | Админ-панель |
| `10-telegram.png` | Telegram-бот (диалог) |
| `11-mobile.png` | Мобильный вид (любой раздел) |

Рекомендуемый размер: **1920×1080** или **1280×800**, формат PNG.

После добавления файлов обновите страницу в браузере (F5).

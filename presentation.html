DBT Hub

Корпоративный портал, который собрал всё
для сотрудника сети точек в одном месте.

Проблема

Как было до портала

  • График смен — в таблицах и чатах, каждый смотрит своё
  • Ежедневные отчёты и поставки — отдельно, без единого стандарта
  • Обучение новых сотрудников — разрозненные материалы
  • Управляющий не видит картину по всей территории из одного окна

Нужна была единая точка входа — не ещё один сервис, а центр операций.

Решение

Что такое DBT Hub

SPA-приложение — личный кабинет для каждого сотрудника сети. Всё, что нужно до, во время и после смены.

Модули · часть 1

Операционный блок

📅

График смен

Неделя и месяц по точке. Праздники РФ. Приглашения на смены и усиление. Желаемые смены подтягиваются из карты возможностей.

🗓

Карта возможностей

Сотрудник отмечает, когда может работать. Управляющий видит карты всех точек территории — удобно планировать график.

📋

Дейли

Ежедневная отчётность по точке. Показатели смены. Экспорт. Автогенерация документов на месяц через раздел «Документация».

💰

Зарплата и КРО

Личные расчёты по сменам. Настройка ключевых результатов (проход) по локации и периоду — для manager и admin.

Модули · часть 2

Поставки, связь, ТО

📦

Заказ поставок

Каталог, формирование заказа по точке, экспорт в Excel. Для старших смен и менеджеров.

💬

Чат с бухгалтерией

Переписка по конкретной точке. Вложения. Работает даже при слабом интернете.

📸

Техобслуживание

Фотоотчёты по смене: загрузка, превью, удаление. Заявки на ремонт — в планах.

📰

Новости + Web Push

Лента для всей сети. Админ шлёт push. Сотрудник включает напоминания о сменах в настройках.

👤

Профиль и настройки

Аватар, визитная карточка, смена пароля, тёмная тема, компактные таблицы, ссылка на Telegram-бот.

Безопасность

  • Bearer-токен на каждый запрос
  • Проверка роли и локации на бэкенде

  • HTTPS, CORS, бэкап БД 14 дней
  • Codeception — unit и functional тесты

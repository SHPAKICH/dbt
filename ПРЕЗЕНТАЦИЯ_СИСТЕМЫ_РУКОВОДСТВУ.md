# DBT Hub — Описание системы для презентации руководству

**Продукт:** DBT Hub (dbthub.ru)  
**Тип:** Корпоративный портал — единый личный кабинет сотрудников сети  
**Дата документа:** март 2025

---

## 1. Назначение системы

DBT Hub — это **внутренняя платформа** для управления персоналом и операциями сети точек (локаций). Система объединяет в одном веб-приложении:

- учёт и доступ сотрудников по ролям;
- графики смен и доступности;
- заказы поставок по точкам;
- ежедневную отчётность (Дейли);
- расчёты по зарплате и КРО (ключевые результаты/проход);
- обучение (тесты, карточки, уроки — блок «Меню Гуру»);
- новости и push-уведомления;
- обратную связь через Telegram-бота.

Цель — **один вход** для сотрудника: профиль, график, зарплата, обучение и операционные задачи в едином интерфейсе с разграничением доступа по ролям.

---

## 2. Роли и доступ

| Роль | Описание | Основные возможности |
|------|----------|----------------------|
| **admin** | Администратор | Полный доступ: пользователи, локации, новости, push-рассылки, настройки системы |
| **manager** | Менеджер | Управление пользователями (в рамках своих локаций), поставки, Дейли, зарплата по привязанным локациям |
| **location_manager** | Менеджер локации | Поставки, Дейли, зарплата по своей локации |
| **senior_teamaker** | Старший тимейкер | Поставки, Дейли по доступным локациям |
| **teamaker** | Тимейкер | График, доступность, профиль, обучение, новости, просмотр своей зарплаты |
| **trainee** | Стажёр | Профиль, график, доступность, обучение, новости |

Менеджеры привязываются к конкретным локациям (`manager_locations`); списки локаций и действия в модулях (Schedule, Supply, Daily, Payroll) ограничиваются этой привязкой.

## 3. Модули и функции

### 3.1. Авторизация и профиль

- **Вход:** по email или телефону + пароль.
- **Сессия:** Bearer-токен (`auth_key`), опция «запомнить меня».
- **Профиль:** личные данные, аватар, выбор шаблона **карточки** (визитка/профиль) и её видимость.

### 3.2. График смен (Schedule)

- Сетка смен по локациям с просмотром по **неделе** и **месяцу**.
- **Приглашения на смены:** отправка, принятие и отклонение приглашений через интерфейс и API.
- Список помощников (helpers) по сменам.

### 3.3. Карта возможностей (Availability)

- **Личная доступность:** отметки «доступен / недоступен» по датам.
- **Командная доступность:** просмотр доступности по выбранной локации/команде (ячейки по датам).

### 3.4. Поставки (Supply)

- Выбор локации, каталог продуктов, формирование заказа, экспорт заказа (в т.ч. в Excel).
- **Доступ:** admin, manager, location_manager, senior_teamaker.

### 3.5. Дейли (Daily)

- Ежедневные отчёты по локациям и пользователям.
- Экспорт отчётов (в т.ч. через PHPSpreadsheet).
- **Доступ:** admin, manager, location_manager, senior_teamaker.

### 3.6. Зарплата (Payroll)

- Данные по локациям, настройка **КРО** (процент прохода `pass_percent`) по локации/году/месяцу.
- Расчёты и раздел **«Мои расчёты по дням»** (my-daily) для сотрудника.

### 3.7. Обучение — Меню Гуру (Guru)

- **Тесты:** вопросы, прохождение, результаты, **таблица лидеров** по тесту.
- **Карточки (TechCard):** материалы с изображениями и текстом.
- **Уроки (TrainingMaterial):** богатый контент (изображения, текст) через редактор TipTap; привязка к тестам.
- **Дашборд обучения:** счётчики прогресса, последние результаты, быстрый доступ к тестам, карточкам и урокам.

### 3.8. Новости

- Лента новостей и просмотр отдельной новости.
- В админке: создание новостей с загрузкой изображений.

### 3.9. Push-уведомления

- **Подписка в браузере:** Web Push (VAPID).
- В админке: статистика подписок и **рассылка** уведомлений.

### 3.10. Админка

- **Дашборд:** сводка по пользователям и локациям.
- **Пользователи:** CRUD, привязка к локациям, роли.
- **Локации:** CRUD, привязка менеджеров (`manager_locations`).
- **Новости:** создание и редактирование.
- **Push:** управление рассылками и просмотр статистики.

### 3.11. Документация и настройки

- Раздел **«Документация»** — внутренняя справка для сотрудников.
- Раздел **«Настройки»** в личном кабинете.

## 4. Интеграции

### 4.1. Telegram-бот обратной связи

- Отдельное приложение (Python, long polling).
- **Команды:** `/start`, `/bug` (ошибка), `/idea` (предложение), `/cancel` (отмена).
- Текст, скриншоты и файлы от пользователя пересылаются в админский чат с указанием типа, имени, username и Telegram ID отправителя.

Таким образом руководство и техподдержка получают обратную связь без выхода из привычного мессенджера.

## 5. Технологический стек

| Слой | Технологии |
|------|------------|
| **Frontend** | Vue 3, Vue Router, Vite 4, Tailwind CSS, Axios; TipTap (редактор для уроков и карточек). |
| **Backend** | PHP ≥7.4, Yii2 (Basic), модули `api` (REST v1) и `guru`. |
| **API** | REST, JSON, авторизация Bearer, CORS для фронтенда. |
| **БД** | MySQL, база `dbt_system`. |
| **Доп. backend** | Bootstrap 5, PHPSpreadsheet (экспорт), Yii2-Imagine (изображения), minishlink/web-push (Web Push), Symfony Mailer. |
| **Telegram-бот** | Python 3, переменные окружения (токен бота, ID админ-чата). |
| **Деплой** | Nginx (статика из `frontend/dist`, `/api` → PHP-FPM), продакшен — dbthub.ru. |

## 6. Ключевые особенности («фишки») для презентации

1. **Единый личный кабинет**  
   Профиль, график, доступность, зарплата, обучение, новости и поставки в одном SPA с автоматическим разграничением по ролям и локациям.

2. **Меню Гуру**  
   Полноценный учебный блок: тесты с таблицей лидеров, карточки, уроки с богатым контентом (TipTap), дашборд прогресса — всё в одном разделе «Обучение».

3. **Гибкие роли и привязка к локациям**  
   Разграничение не только по ролям, но и по привязке менеджеров к локациям: ограничение списков и действий в Schedule, Supply, Daily, Payroll.

4. **Приглашения на смены**  
   Отправка, принятие и отклонение приглашений на смены через интерфейс и API — прозрачный процесс согласования смен.

5. **Web Push**  
   Подписка в браузере и рассылка из админки (VAPID) — возможность оперативно доводить новости и напоминания до сотрудников без email.

6. **Экспорт данных**  
   Выгрузка заказов поставок и отчётов Дейли (в т.ч. в Excel) для отчётности и планирования.

7. **КРО в зарплате**  
   Настройка процента прохода (pass_percent) по локации и периоду для расчётов — учёт ключевых показателей в оплате.

8. **Карточки профиля**  
   Выбор шаблона карточки (визитки) и управление видимостью в профиле — персонализация и брендинг.

9. **Telegram-обратная связь**  
   Отдельный бот для приёма багов и идей с пересылкой в админский чат — быстрый канал обратной связи от сотрудников.

10. **Адаптивный интерфейс**  
    Сайдбар с мобильным меню, градиентный дизайн (например, gradient-solar-coral), удобство работы с телефона и планшета.

---

## 7. Безопасность и надёжность

- Авторизация по токену (Bearer), защита API от неавторизованного доступа.
- Разделение прав по ролям и локациям на уровне API и интерфейса.
- CORS и настройка окружения (frontendUrl, VAPID) для корректной работы в продакшене.
- Деплой по HTTPS (Let's Encrypt), статика и API через Nginx.

---

## 8. Резюме для руководства

**DBT Hub** — это корпоративный портал, который:

- даёт **одну точку входа** для сотрудников по всем задачам: от графика и зарплаты до обучения и новостей;
- **разграничивает доступ** по ролям и привязке к локациям;
- включает **обучение** (Меню Гуру) с тестами, карточками и уроками;
- поддерживает **операционную работу**: поставки, Дейли, приглашения на смены, КРО в зарплате;
- обеспечивает **коммуникацию**: новости, Web Push, обратная связь через Telegram-бота;
- позволяет **выгружать данные** (заказы, отчёты) для анализа и отчётности.

Система развёрнута в продакшене (dbthub.ru), фронтенд и бэкенд документированы, настроены примеры Nginx и деплой для поддержки и развития платформы.

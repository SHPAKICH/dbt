## 3. КРАТКОЕ ОПИСАНИЕ МЕСТА ПРОХОЖДЕНИЯ ПРАКТИКИ

**Общие сведения о предприятии**

Индивидуальный предприниматель Левитина О. Ю. ведёт деятельность в сфере разработки и сопровождения информационных систем для сетевого бизнеса. В рамках практики разрабатывался внутренний корпоративный портал **DBT Hub** (dbthub.ru) — единый личный кабинет сотрудников сети точек (заварщики чая, старшие смены, менеджеры точек, управляющие, администраторы). Портал объединяет операционные задачи, обучение и внутренние коммуникации с разграничением прав по ролям и привязкой к локациям.

**Подразделение и рабочее место практиканта**

В период преддипломной практики я продолжал разработку клиентской части DBT Hub. Основные задачи включали: доработку модуля графика смен и «карты возможностей» (доступность сотрудника по датам), интерфейса ежедневной отчётности «Дейли», страницы зарплаты и КРО (ключевые результаты), модуля заказа поставок, чата с бухгалтерией по точке, модуля технического обслуживания (фотоотчёты по сменам), ленты внутренних новостей с Web Push-уведомлениями, обучающего раздела «Гуру» (карточки, уроки, тесты) и страницы профиля/настроек. Дорабатывалась также часть административной панели (управление пользователями и локациями) и интеграция с Telegram-ботом для уведомлений сотрудников.

Работа велась в команде с backend-разработчиком (Yii2 REST API на PHP) под непосредственным руководством заказчика. Клиентская часть — SPA на **Vue 3 + Vite + Tailwind CSS**, написанная на JavaScript; общение с сервером — через REST с авторизацией по токену; для контента уроков и описаний используется WYSIWYG-редактор на базе TipTap; Telegram-бот реализован отдельным сервисом на Python (aiogram). Производственная мощность подразделения соответствует задаче — небольшая команда, итерационная разработка с регулярными релизами.

Рабочее место организовано на базе персонального компьютера с доступом в Интернет, системой контроля версий Git и набором ПО для разработки на Vue 3 / Vite / Node.js (frontend), PHP 8 / Yii2 (backend) и Python 3 (telegram-bot). Заказчик предоставлял разъяснения по бизнес-процессам сети, фирменные материалы и доступ к тестовой среде; регулярные согласования позволяли уточнять требования без простоя по задачам.

**Техника безопасности.** При работе с ПК соблюдались требования по электробезопасности и эргономике рабочего места, регламент перерывов и обращения с конфиденциальными данными (учётные записи сотрудников, персональные данные, доступы к серверу).

## 5. ЗАКЛЮЧЕНИЕ

Прохождение преддипломной практики в ИП Левитина О. Ю. стало логичным продолжением работы над корпоративным веб-приложением **DBT Hub** и поддержало подготовку дипломного проекта: от уточнения и фиксации требований заказчика до реализации и сопровождения пользовательских сценариев на уже эксплуатируемом портале (график смен, карта возможностей, «Дейли», поставки, зарплата, чат с бухгалтерией, техобслуживание, обучение «Гуру», новости с Web Push, профиль и настройки).

В ходе практики я углубил работу на стеке **Vue 3 + Vite + Tailwind CSS** с REST API на **Yii2 (PHP)**: компонентная архитектура SPA, маршрутизация (`vue-router`), работа с API через `axios`, очистка пользовательского HTML через `DOMPurify`, контентный редактор на базе `@tiptap/vue-3`. Отдельно проработаны: разграничение интерфейса по ролям (admin / manager / location_manager / senior_teamaker / teamaker / trainee), устойчивость интерфейсов к нестабильной сети, Web Push-уведомления, интеграция с Telegram-ботом на Python (aiogram) и сборка/деплой через Vite и Nginx с прокси `/api` на PHP-FPM.

Регулярные согласования с заказчиком и backend-разработчиком позволили планировать доработки, уточнять формулировки интерфейса и своевременно вносить правки, а также сопроводить релизы документацией (`README.md`, `ADMIN_PANEL.md`, `TROUBLESHOOTING.md`) и регламентом резервного копирования БД.

В целом этап укрепил связь учебных компетенций с полным циклом задач по развитию корпоративного портала — от проектирования отдельных модулей и мер безопасности до сопровождения веб-приложения в реальной эксплуатации и подготовки его к дальнейшему развитию (расширение административной аналитики, внедрение заявок на техническое обслуживание, развитие обучающего раздела).
